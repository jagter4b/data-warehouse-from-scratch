# Olist ML Analytics Dashboard

This Streamlit application visualizes the predictive insights generated by the Olist Data Warehouse Machine Learning Layer.

The application connects read-only to the Gold schema and visualizes outputs from the One Big Tables (OBTs) and the 7 ML Result Tables across Customers, Sellers, and Orders.

## Features
- **Dark Theme:** Fully customized dark mode UI via `.streamlit/config.toml` and custom CSS.
- **Robust Caching:** Utilizes `@st.cache_data(ttl=3600)` to ensure snappy UI interaction without hammering the database.
- **Demo Mode Fallback:** Automatically degrades to loading data from local CSV exports (`data/*.csv`) if the SQL Server connection fails, ensuring the app works perfectly on Streamlit Cloud without an exposed local database.
- **Rich Visualizations:** Employs `plotly.express` for dynamic donuts, histograms, box plots, and scatter plots.

## Project Structure
- `app.py`: Main entry point and pipeline health summary.
- `pages/`: 
  - `1_Customer_Intelligence.py`: Segmentation, Churn, LTV.
  - `2_Seller_Intelligence.py`: Performance Scoring, Churn Risk.
  - `3_Order_Intelligence.py`: Delivery Risk, Review Predictions.
- `components/`: Modularized database fetching (`db.py`), charting (`charts.py`), and sidebar rendering (`filters.py`).
- `data/`: Extracted CSV copies of the database used exclusively for Demo Mode.

## Prerequisites
- Python 3.9+
- Packages listed in `requirements.txt`

## Running Locally
1. Navigate to the `streamlit` directory:
   ```bash
   cd streamlit
   ```
2. Install the requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```

## Cloud Deployment (Streamlit Cloud)
To deploy this application to Streamlit Cloud:
1. Connect your GitHub repository to Streamlit Cloud.
2. Select `streamlit/app.py` as the main file path.
3. **Database Connectivity:** Because the source database is a local SQL Server instance on your Windows machine, Streamlit Cloud cannot natively reach it without a reverse tunnel (e.g., `ngrok`). 
4. **Demo Mode (Recommended for Cloud):** You do *not* need to set up any `secrets.toml` variables. The application will automatically detect the missing connection variables and fallback to **Demo Mode**, loading the pre-exported CSVs from the `streamlit/data` directory flawlessly.

## Configuration (For Live Database connection)
If you wish to expose your local database or connect to an Azure SQL instance, copy the template:
```bash
cp .streamlit/secrets.toml.template .streamlit/secrets.toml
```
Update the `.streamlit/secrets.toml` with your host, port, and database name.
